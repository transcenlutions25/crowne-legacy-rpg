# Cross-Game Principles

Crowne Legacy Mobile and the future main 3D game will be two clients connected to one persistent world.

1. One player identity across both games.
2. One authoritative wallet and transaction ledger.
3. One character, relationship, faction, property, business, inventory, mission, and consequence state.
4. Every cross-game mutation receives a unique receipt so rewards and purchases cannot duplicate.
5. Offline mobile actions queue safely and reconcile when connectivity returns.
6. Conflicts resolve through explicit version rules, never silent overwrites.
7. Mobile remains a complete standalone game, not a required remote control.
8. The main game remains playable without forcing constant phone interaction.
9. Cross-game features add strategic depth and continuity rather than artificial chores.
10. Existing Crowne Legacy characters and canon remain protected and additive.
